## Conteúdos aprendidos 
Hoje assisti ao vídeo do canal o curso de html e css, o começo é “Domínio e hospedagem”. Servidor e acesso, o professor explicando para que outras pessoas acessem seu site os arquivos (HTML e CSS) precisam ficar hospedados em um servidor “um computador ligado 24h a internet”. Os arquivos apenas no seu próprio computador tornam o site inacessível para o público. O que é domínio, é o nome único que identifica o site na rede. É o endereço as pessoas digitam no navegador. O que é hospedagem, é o local físico, espaço no servidor onde o site fica armazenado, sem ela o site não existe no ambiente online. URL, é o endereço completo que digitamos no navegador, uma URL pode incluir o protocolo, “como https”, subdomínio “como www”, o domínio e o caminho específico para uma pág ou arquivo dentro no servidor.
