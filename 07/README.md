## Conteúdos aprendidos 
 Hoje assisti ao vídeo do canal o curso de html e css, o começou “Seu primeiro código HTML” O professor explicou a importância de organizar os arquivos do projeto. Ele mostrou como criar pastas para separar os arquivos, como HTML, CSS e imagens, facilitando a localização. Agora estrutura básica, o professor mostrou como usar o atalho que é seguido da tecla enter para criar automaticamente um documento HTML5. O explicou a função das principais tags, como head, que é contém as configurações da página, body que onde fica o conteúdo exibido, além das tags meta charset=“UTF-8”, que garante a exibição correta dos caracteres, e viewport, que ajuda a página a se adaptar a diferentes tamanhos de tela. O professor apresentou as tags de título e de parágrafo, também explicou que as tags de título organizam o conteúdo da página e não devem ser usadas apenas para aumentar o tamanho da letra. O apresentou as tags sem fechamento, como hr, meta e img, ele explicou que essas tags não precisam de uma tag de fechamento para funcionar.
