## Conteúdos aprendidos 
O professor explicou a diferença entre as tags de formatação em HTML. A tag <b> texto em negrito, enquanto <strong> indica que o conteúdo tem importância. Já a tag <i> altera a aparência do texto, e <em> indica ênfase. O professor destacou que o HTML deve definir o significado do conteúdo, enquanto o CSS deve cuidar da aparência, como cores, fontes e estilos. Apresentou o atalho Ctrl + Shift + P no Visual Studio Code, que facilita o uso de comandos para envolver o textos com tags HTML e agilizar a escrita do código.
