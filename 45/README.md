## Conteúdos aprendidos 
O professor explicou o como personalizar os textos utilizando CSS o apresentou a propriedade font-weight que controla a espessura das letras, e font-style, permite aplicar estilos como o itálico que demonstrou text-decoration, utilizada para adicionar efeitos como o sublinhado. A seguida, ensinou o shorthand font que permite reunir várias configurações de fonte em uma única declaração, seguindo a ordem correta das propriedades essa é a técnica facilita a organização do código CSS. O destacou as variações de peso e estilo disponíveis dependem da família tipográfica escolhida.
