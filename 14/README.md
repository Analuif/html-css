## Conteúdos aprendidos 
 Hoje assisti ao vídeo do canal o curso de html e css, o começou “A tag img em HTML5” agora o explicou a estrutura da tag  que é apresentou os atributos principais, o src indica o local onde está o arquivo da imagem, enquanto o alt fornece uma descrição da imagem, ajudando na acessibilidade para usuários. Ele ensinou o atalho Ctrl + Espaço no Visual Studio Code, esse atalho mostra a lista de arquivos da pasta, facilitando a escolha do arquivo correto e evitando erros ao digitar o nome. O professor mostrou como é adicionar imagens que estão salvas em subpastas do projeto. Ele explicou que também é possível exibir imagens usando uma URL. Nesse caso a imagem fica armazenada em outro servidor, e o HTML utiliza o endereço da imagem para carregá-la na página…
