## Conteúdos aprendidos 
O professor explicou como usar diferentes tags HTML para organizar e apresentar conteúdos. A tag <code> exibe trechos de código com uma fonte monoespaçada, enquanto <pre> mantém os espaços e as quebras de linha originais, sendo útil para blocos maiores de código. Ele apresentou a tag <q>, usada para citações curtas, e <blockquote>, utilizada para citações longas, com recuo no texto o atributo cite pode indicar a fonte da citação. A tag <abbr> permite identificar abreviações e, com o atributo title, mostrar seu significado completo ao passar o mouse. Por fim, a tag <bdo> permite alterar a direção do texto, da esquerda para a direita ou no sentido contrário, embora seja pouco utilizada no desenvolvimento web.
