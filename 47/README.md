## Conteúdos aprendidos 
O professor que ensinou a utilizar fontes baixadas a internet em projetos HTML5 e CSS3, ele explicou o como escolher as fontes, verificar o suporte a acentos e importar os arquivos “otf e ttf” o usando as regras font-face no CSS. O recomendou organizar os arquivos em uma pasta específica, como fontes e configurar corretamente os caminhos no código por fim, o mostrou que é possível a combinar fontes externas com o Google Fonts no mesmo projeto.
