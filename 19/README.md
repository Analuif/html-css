## Conteúdos aprendidos 

O professor iniciou o estudo de CSS (Cascading Style Sheets), que significa Folhas de Estilo em Cascata. Essa tecnologia é usada para mudar a aparência das páginas HTML o permitindo adicionar cores, fontes e tamanhos. Enquanto o HTML organiza o conteúdo, o CSS cuida da parte visual. Na aula, foi apresentado o CSS inline, que permite aplicar estilos diretamente nas tags HTML usando o atributo style. O professor mostrou como alterar a cor de fundo com background-color, a cor do texto com color e o tipo de fonte com font-family. O professor também explicou que o CSS inline não é recomendado para projetos maiores, pois deixa o código confuso, dificulta as alterações e exige muito trabalho repetido. No próximo capítulo, serão apresentadas formas mais organizadas e eficientes de aplicar estilos às pág web.
