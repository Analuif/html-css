## Conteúdos aprendidos 
O professor apresentou três ferramentas online gratuitas para criar paletas de cores para sites. O Adobe Color permite combinar cores com base no círculo cromático e extrair paletas de imagens. O Paletton possibilita criar combinações e visualizar como elas ficam aplicadas ao layout de um site, já é o Coolors gera paletas rapidamente e permite manter as cores escolhidas enquanto sugere outras opções.
