## Conteúdos aprendidos 

O que é um favicon? O favicon é um pequeno ícone que aparece do navegador ao lado do título do site. Ele ajudaria usuário a identificar uma página às várias abertas, como a acontecer no Google, Facebook e YouTube. Como criar um favicon. O professor explicou quatro maneiras de conseguir um favicon, a buscar ícones o prontos no Icon Archive, desenhar um ícone no favicon.cc, a criar ícones com letras ou emojis no favicon.io e converter uma imagem, como um logotipo PNG, para o formato ICO. Como adicionar a HTML. Para colocar o favicon no site, é necessário inserir o código dentro da seção <head> do arquivo HTML. No Visual Studio Code, podemos digitar link e escolher a sugestão link:favicon. Depois, basta indicar o arquivo correto no atributo heaf. O atalho Ctrl+Espaço, usado o dentro das aspas desse atributo, ajudado a localizar o arquivo salvo na pasta do projeto.
