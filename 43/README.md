# Famílias de fontes com CSS

## Informações

- Link do vídeo: https://youtu.be/dMp1UFD8_lE?si=MPZdY_FMHqC2Jty0
- Duração do Vídeo: 12 minutos
- Data de visualização: 15/11/26

## Conteúdos aprendidos 
Ele explicou como utilizar a propriedade font-family no CSS pra o escolher as fontes de um site, a importante de definir as fontes alternativas caso a principal não esteja disponível no dispositivo o usuário. O apresentou os combinações de fontes compatíveis com diferentes a sistemas e as famílias genéricas serif, sans-serif e monospace. Por fim, o mostrou como utilizar o VS Code para o escolher fontes e aplicar estilos aos títulos, além de introduzir a propriedade font-size que define o tamanho do texto.
