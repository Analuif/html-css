## Conteúdos aprendidos 

O professor explicou que as listas ajudam a organizar informações em páginas web. No HTML, existem três tipos: ordenadas, não ordenadas e de definição. As listas ordenadas usam a tag <ol>  e servem para itens que seguem uma sequência. O atributo type permite escolher números, letras ou algarismos romanos, enquanto a start define o início da contagem. As listas não ordenadas usam a tag <ol>  e são indicadas quando a ordem dos itens não importa. Com o atributo type, é possível escolher marcadores em forma de círculo preenchido (disc), círculo vazio (circle) ou quadrado (square).
