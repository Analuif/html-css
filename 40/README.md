## Conteúdos aprendidos 
O professor explicou na prática, o primeiro criou a estrutura HTML com títulos e parágrafos e utilizou a tag <main> para organizar o conteúdo principal. A seguida, escolheu uma paleta de cores no Adobe Color e aplicou os estilos com CSS o incluindo degradês no fundo, centralização do conteúdo com margin o auto, cantos arredondados com border-radius e sombras com box-shadow. O utilizou rgba() para ajustar a transparência das sombras. Dessa forma, criou um exemplo real de página web, mostrando como combinar cores, organização e efeitos visuais pra melhorar a aparência do site.
