## Conteúdos aprendidos 

O professor explicou como usar CSS interno para organizar melhor o código HTML. O estilo inline, que é colocado diretamente nas tags, pode deixar o código e dificultar as alterações. Para aplicar o CSS interno, utiliza-se a tag <style> dentro da seção <head> do documento HTML. Também foram apresentados seletores como body, h1, h2 e p, que permitem aplicar estilos aos elementos da página de forma mais prática. Essa técnica ajudou a separar o conteúdo HTML da aparência definida pelo CSS, deixando o código mais organizado. Porém, ela pode aumentar o número de linhas e dificultar o uso dos mesmos estilos em várias páginas. Por isso, o professor introduziu a próxima etapa do curso usando CSS externo.
