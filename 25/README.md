## Conteúdos aprendidos 
O professor iniciou o estudo dos hiperlinks, também conhecidos como links, explicando que eles permitem navegar entre diferentes páginas e sites na internet. Também apresentou como o Google utiliza links para encontrar e organizar páginas nos resultados de pesquisa. Durante a aula, foi explicado o conceito de SEO (Search Engine Optimization), que reúne técnicas para melhorar a visibilidade de um site nos mecanismos de busca. O professor reforçou que é importante aprender bem HTML antes de avançar para CSS a aula também introduziu o uso de links externos e dos atributos target e rel, que serão explorados nas atividades práticas.
