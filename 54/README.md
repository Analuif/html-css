## Conteúdos aprendidos 
O professor explicou que os elementos HTML são representados como caixas, compostas por conteúdo, borda (border) preenchimento interno (padding), margem externa (margin) e contorno (outline). O apresentou as propriedades width e height, que definem a largura e a altura do conteúdo. O explicou a diferença entre elementos box-level, o começam em uma nova linha, e inline-level, ocupam apenas o espaço necessário para o conteúdo, sem iniciar uma nova linha.
