## Conteúdos aprendidos 
O professor explicou como o criou listas o dentro de outras listas usando as tags <ol> e <ul>. Essa técnica permite organizar o informações em diferentes níveis, como no exemplo das linguagens de programação favoritas, a separadas por categorias. Também o mostrou como misturar listas ordenadas e não ordenadas e personalizar os marcadores com o atributo type. Nas listas ordenadas, o atributo start permite escolher o número inicial da contagem. O professor que apresentou uma dica para facilitar a edição do código usar a tecla Alt para criar vários cursores no editor e alterar diferentes linhas ao mesmo tempo, tornando o trabalho mais rápido
