## Conteúdos aprendidos 

O professor explicou a importante e criar uma pasta chamada mídia no dentro da pasta principal do site para guardar os arquivos de áudio utilizados na página. Essa organização facilita encontrar os arquivos e ajuda a manter o projeto organizado. Por exemplo, dentro da pasta midia, podemos guardar músicas e sons nos formatos MP3, OGG ou WAV. Depois, no código HTML, usamos a tag <audio> e o elemento <source> para indicar o caminho do arquivo que será reproduzido. Assim, os arquivos ficam separados do código HTML, facilitando a manutenção e evitando confusões durante o desenvolvimento do site.
