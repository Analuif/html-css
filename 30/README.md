## Conteúdos aprendidos 
O professor explicou como usar diferentes tags HTML para formatar os textos. A tag <mark> destaca uma parte do texto e permite mudar a cor com CSS. A tag <small> deixa o texto menor, enquanto <big> aumenta o tamanho, mas está obsoleta no HTML5. Também a foram apresentadas as tags <del>, indica um texto removido, e <ins>, indica um texto inserido. Já <sup> coloca caracteres acima da linha, como em potências, e <sub> colocar caracteres abaixo, como em fórmulas químicas. Durante a aula prática, o professor utilizou o Visual Studio Code para demonstrar essas formatações. Também mencionou os cursos gratuitos da Recode, voltados à aprendizagem de tecnologia e à preparação para o mercado de trabalho.
