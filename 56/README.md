## Conteúdos aprendidos 
O professor que explicou,  margin define o espaço externo de um elemento e que margin auto pode ser usado para centralizá-lo horizontalmente. O apresentou outline, um contorno que destaca elementos sem alterar o espaço ocupado no layout. O ensinou o uso de shorthands, a permitem configurar as várias propriedades em uma única declaração. A propriedade border reúne espessura, estilo e a cor, enquanto margin e padding permitem definir os espaçamentos dos quatro lados usando um, dois ou quatro valores, simplificando o código CSS.
