## Conteúdos aprendidos 
O professor explicou que o HTML deve ser usado para organizar o conteúdo e indicar seu significado, como títulos, parágrafos e endereços, não para definir sua aparência. Tags como <center> e <font>, além do atributo bgcolor, tornaram-se obsoletos no HTML5 e devem ser evitados. A parte visual, como cores, o tamanhos e fontes, deve ser feita com CSS. O professor também o apresentou a tag <address>, que permite identificar informações de contato, tornando o código mais organizado e o significado claro para navegadores e mecanismos de busca.
