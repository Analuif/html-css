## Conteúdos aprendidos 
O professor explicou como colocar vídeos diretamente em um site o usando HTML. Para funcionar em diferentes navegadores, é possível oferecer formatos como MP4, M4V, WebM e OGV. A tag <source> indica os arquivos disponíveis, o atributo poster define a imagem de capa e o atributo controls permite que o usuário controle a reprodução do vídeo. Também foi destacado que hospedar vídeos no próprio servidor pode consumir muita banda e aumentar os custos do projeto. Por isso, é a importante avaliar essa opção antes de utilizá-la. O professor mencionou a Recode, organização que oferece no cursos de tecnologia para capacitação profissional, e explicou que os certificados do curso são válidos em todo o Brasil após a conclusão dos cinco módulos previstos.
