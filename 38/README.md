## Conteúdos aprendidos 
O professor que ensinou as formas de identificar os códigos de cores em sites e documentos uma delas é utilizar o GIMP para abrir uma captura de tela e selecionar uma cor com a ferramenta conta-gotas, embora esse método possa apresentar pequenas às diferenças na tonalidade. O apresentou a extensão ColorZilla, que permite selecionar cores diretamente no navegador e copiar seus códigos hexadecimais. Por fim, demonstrou como utilizar esses códigos no Adobe Color para criar paletas harmoniosas para projetos web.
