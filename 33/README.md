## Conteúdos aprendidos 
O professor explicou como otimizar imagens para diferentes dispositivos, melhorando o carregamento e o desempenho do site. Usar imagens muito grandes em celulares, mesmo reduzindo seu tamanho com CSS, pode deixar a página mais lenta, evitar esse problema, ele demonstrou como criar três versões da mesma imagem no GIMP, com tamanhos de 300x300, 700x700 e 1000x1000 pixels. Os arquivos foram exportados em PNG e organizados na pasta ex-11 do projeto.O professor também incentivou a criação de artes para divulgar o curso e o uso do GitHub para compartilhar os projetos. Ao final, apresentou o tema da próxima aula: a tag <picture>, que permite selecionar imagens adequadas para diferentes tamanhos de tela.
