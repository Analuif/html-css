# Capturando as fontes usadas em um site 

## Informações

- Link do vídeo: https://youtu.be/XTtfM0L7Co0?si=KMbsoOtlPyXCMQiA
- Duração do Vídeo: 12 minutos
- Data de visualização: 15/11/26

## Conteúdos aprendidos 
Ele que o apresentou, extensão Fonts Ninja para Google Chrome a identifica as fontes usadas em páginas o mostrando da família tipográfica, tamanho, peso e cores. O explicou que a ferramenta pode não reconhecer textos que fazem parte às imagens. Após identificar uma fonte, é possível procurá-la no Google Fonts ou no DaFont para utilizá-la em projetos próprios o recomendou desativar extensões quando não estiverem em uso para melhorar o desempenho do navegador.
