## Conteúdos aprendidos 
Ele que explicou como utilizar a propriedade box-shadow para criar sombras e dar profundidade aos elementos de um site. Demonstrou como ajustar a posição horizontal e vertical, o desfoque e a cor da sombra. O valor inset, que cria sombras internas e ensinou a usar o DevTools para testar os efeitos. O recomendou utilizar transparência para deixar as sombras mais suaves e naturais, além pra mostrar como o corrigir problemas de margens no rodapé.
