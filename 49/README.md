# Detectando fontes dentro de imagens 

## Informações

- Link do vídeo: https://youtu.be/i_c5Fzk807M?si=pmXwx1fkYQXqGD6k

## Conteúdos aprendidos 
Ele explicou três ferramentas para identificar as fontes em imagens WhatFontIs, Font Squirrel e MyFonts. O WhatFontIs é a possível ajustar o brilho e o contraste, recortar caracteres e confirmar as letras identificadas. Ele destacou que nenhuma ferramenta é o totalmente precisa os resultados dependem da qualidade da imagem e do estilo da fonte. Também alertou que algumas fontes são comerciais e exigem licença de uso q recomendação é o começar pelo WhatFontIs e testar as outras ferramentas caso necessário.
