## Conteúdos aprendidos 
O professor que explicou a evolução do HTML, mostrando como as tags semânticas do HTML5 facilitam a organização e dão significado ao conteúdo da página. Apresentou as principais tags header (cabeçalho), nav (navegação), main (conteúdo principal), section (seções), article (conteúdo independente), aside (conteúdo complementar) e footer (rodapé). Também demonstrou como utilizar o CSS3 para personalizar o layout, ajustando cores de fundo, margens e espaçamentos internos.
