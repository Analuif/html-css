# Manutenção em sites hospedados no GitHub 

## Informações

- Link do vídeo: https://youtu.be/ejQwG2cvWxg?si=Gk_GUZPlxw9DqNnc
- Duração do Vídeo: 9 minutos

## Conteúdos aprendidos 
 
Ele explicou como identificar e corrigir um problema visual no topo do site, causado pelo uso incorreto de margin em vez de padding no cabeçalho. A correção foi feita no Visual Studio Code, junto com ajustes nos links do menu de navegação. Depois, as alterações foram salvas com um commit no GitHub Desktop e enviadas para o repositório remoto. Por fim, foi explicado que a atualização no GitHub Pages pode levar de 30 segundos a 3 minutos para aparecer no site publicado.
