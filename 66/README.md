## Conteúdos aprendidos 
O professor que explicou como criar as variáveis no CSS para reutilizar cores e fontes em diferentes a partes do site, facilitando futuras alterações. Demonstrou como declará-las em root usando e como acessá-las com var(). O apresentou o seletor universal *, utilizado para redefinir margens e espaçamentos internos, e destacou a importância de controlar a largura do conteúdo para melhorar a adaptação do site a diferentes telas.
