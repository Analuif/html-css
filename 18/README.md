## Conteúdos aprendidos 
O professor explicou como criar links para baixar arquivos usando HTML5, como documentos PDF e arquivos compactados em ZIP. Para isso, utiliza-se a tag <a> para indicar o caminho do arquivo e o atributo download para iniciar o download em vez de apenas abrir o arquivo no navegador. Também foi apresentado o atributo type, que informa o tipo de arquivo, como application/pdf para PDF e application/zip para ZIP. Para identificar esses tipos corretamente, o professor recomendou consultar o site oficial IANA. Na prática, ele mostrou como organizar os arquivos em pastas e utilizar listas HTML para apresentar diferentes opções de download de um e-book.
