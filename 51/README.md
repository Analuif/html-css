## Conteúdos aprendidos 
O professor que o explicou como utilizar o atributo id para identificar e estilizar elementos específicos do HTML. No CSS, o símbolo # é usado para selecionar um elemento pelo seu ID. O demonstrou como a criar um arquivo CSS externo para as organizar os estilos e destacou a importância de evitar erros de digitação. Ele explicou a diferença entre id a usado para identificar um elemento de forma única, e class, que pode ser aplicada a vários elementos.
