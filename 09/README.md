## Conteúdos aprendidos 
Hoje assisti ao vídeo do canal o curso de html e css, o começou “Hierarquia de Títulos”. Agora é Hierarquia Semântica, o professor explicou que os títulos, uma hierarquia do <h1> ao <h6> essa que é organização ajuda a estruturar o conteúdo da página e facilita a compreensão por buscadores e leitores de tela. Formação via CSS, ele explicou que as tags de título servem para organizar o conteúdo da página o tamanho, a cor e a aparência dos títulos devem ser definidos pelo CSS, e não pelo HTML. Prática, ele criou um documento HTML usando a hierarquia de títulos, também utilizou o texto Lorem Ipsum para preencher a página e realizar os testes..
