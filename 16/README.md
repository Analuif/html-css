## Conteúdos aprendidos 

O professor criou uma página web com quatro imagens, organizadas de preferência em duas colunas. Ao clicar em cada imagem, o vídeo correspondente deve aparecer na própria página usando a tag <iframe>. Também é necessário criar um botão para voltar e um link “Ver curso completo”, que abre a playlist oficial do YouTube em uma nova. O objetivo é praticar o uso de links, a navegação e a incorporação de vídeos sem se preocupar com o design. Os arquivos necessários estão disponíveis no GitHub do curso. É importante concluir o desafio antes de avançar para o capítulo 12, quando o começa no estudo de CSS, responsável pela aparência das páginas web.
