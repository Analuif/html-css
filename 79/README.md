## Conteúdos aprendidos 
O GitHub funciona como uma rede social para programadores, permitindo o seguir desenvolvedores e empresas, além a marcar projetos favoritos com estrelas. Ele que apresentada a ferramenta GitHub Explore, a ajuda a encontrar projetos populares e os novos desenvolvedores. A aba Issues permite relatar problemas, a tirar dúvidas e colaborar com outros projetos. Ele que mostrada a opção de adicionar uma mensagem de status ao perfil para o informar o que está aprendendo ou o fazendo.
