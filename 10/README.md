## Conteúdos aprendidos 
Hoje assisti ao vídeo do canal o curso de html e css, o começou “Símbolos e Emoji no seu site”. Boas práticas, o professor explicou que a tag que é deve ser usada apenas para fazer uma quebra de linha. Para criar espaços entre os elementos da página, o correto é utilizar o CSS, evitando o uso excessivo dessa tag. Ele mostrou como inserir comentários no código HTML, esses comentários servem para fazer anotações e organizar o código, mas não aparecem no navegador. Uso de emojis, ele explicou como é adicionar emojis em uma página HTML. O mostrou como encontrar o código de cada emoji no site Emojipedia e utilizá-lo no código da página..
