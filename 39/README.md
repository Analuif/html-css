## Conteúdos aprendidos 
O professor ensinou como criar degradês com CSS para deixar os sites mais bonitos e harmoniosos o apresentou no linear-gradient, a cria transições de cores em diferentes direções e o radial-gradient, a forma degradês circulares ou elípticos. O demonstrou o uso do Adobe Color para escolher combinações de cores e explicou como manter o fundo fixo durante a rolagem da página usando background-attachment, fixed. Por fim, destacou a importância de combinar as cores com moderação para manter um design equilibrado.
