## Conteúdos aprendidos 

O professor apresentou o CSS externo, uma forma prática de aplicar estilos às páginas HTML. Quando um site possui várias páginas, é melhor criar um arquivo separado, geralmente chamado style.css. Assim, é possível alterar a aparência de todas as páginas conectadas a esse arquivo sem precisar repetir o mesmo código. Para conectar o CSS externo ao HTML, utiliza-se a tag <link> dentro da seção <head>.  O professor também apresentou a regra @charset”UTF-8”;, que ajuda a garantir a leitura correta de acentos e caracteres especiais. Também explicou que é possível combinar os três tipos de CSS: inline, interno e externo. Em situações de conflito, o estilo inline geralmente tem prioridade sobre os outros, embora a prioridade também dependa das regras de especificidade e da ordem do código. Por fim, recomendou dar preferência ao CSS externo, pois ele facilita a organização e a manutenção do site.
