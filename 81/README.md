## Conteúdos aprendidos 
O explicado como acessar o GitHub Desktop com uma conta o clonar repositórios para uma pasta local e configurar o nome e o e-mail usados nos registros de alterações.Ele que foi mostrado como salvar as mudanças com commit e enviá-las ao GitHub com push. A foram apresentados os cuidados para usar o programa em outro computador, incluindo remover o repositório local, sair da conta e limpar os dados pessoais das configurações.
